## decisions — почему именно так

| Страница | Решение |
|---|---|
| [[decisions/separate-package]] | почему генератор выделен из `partest` в свой дистрибутив |
| [[decisions/methodology-upstream]] | методология живёт в `partest`; здесь её не форкают |
| [[decisions/banner-overwrite]] | перезаписываются только файлы с баннером |
| [[decisions/no-domain]] | в генерируемом коде нет продуктового домена; где граница |
| [[decisions/docs-in-wheel]] | `partest_gen/docs` генерируется, `ships_in_wheel` решает состав |
